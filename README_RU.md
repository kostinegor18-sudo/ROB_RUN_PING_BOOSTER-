# ROB RUN PING BOOSTER — Windows 11 x64

## Быстрый способ получить EXE через GitHub Actions
1. Создайте пустой репозиторий GitHub.
2. Загрузите в него все файлы и папку `.github` из этого проекта.
3. Откройте вкладку **Actions**.
4. Выберите **Build Windows EXE** → **Run workflow**.
5. После завершения сборки скачайте артефакт `ROB-RUN-PING-BOOSTER-Windows-x64`.
6. Внутри будет `ROB RUN PING BOOSTER.exe`.

## Сборка локально в Windows 11
Установите .NET 8 SDK, откройте PowerShell в папке проекта и выполните:
```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build-windows.ps1
```
Результат: `publish\ROB RUN PING BOOSTER.exe`.

## Реализовано в первой версии
- WinForms интерфейс: тёмная тема, зелёные акценты.
- Ping через ICMP.
- Приближённый jitter (разница между соседними успешными измерениями).
- Доля потерянных ICMP-пакетов.
- График последних измерений.
- Информация об активных сетевых адаптерах.
- Базовая диагностика нескольких контрольных узлов.

## Честные ограничения
Публичные узлы 1.1.1.1 и 8.8.8.8 не являются серверами ROB RUN. Чтобы показывать именно игровой ping, нужно получить удалённый IP активного соединения игры и проверить, что это игровой endpoint. ICMP может блокироваться или обрабатываться иначе, чем игровой UDP-трафик.

Кнопка диагностики пока не меняет настройки Windows. Универсальные реестровые и TCP-твики не гарантируют снижения пинга; необоснованное изменение настроек может навредить. Автоматические изменения будут добавляться после точной диагностики и с механизмом отката.
